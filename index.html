    Point any OpenAI or Anthropic compatible client at the Command Code provider endpoint.

OpenAI-compatible endpoint

  -H "Authorization: Bearer <CMD_API_KEY>" \
  -H "Content-Type: application/json" \

    "model": "deepseek/deepseek-v4-flash",
    "messages": [{"role": "user",

FAQ

Questions, answered

Everything you need to know before subscribing to GOAT.

What models are available on the GOAT plan?

GOAT offers both open and closed models. Switch any time with /model in interactive mode — DeepSeek, Kimi, GLM, Qwen, MiniMax, MiMo, Grok, Gemini, Mistral, LongCat, Ling, and more, plus select premium models like Claude Sonnet 5.5 and Claude Haiku 5.5.

What are the usage limits?

$14 of usage in any 5 hours, $35 in any 7 days, and $70 per month. Limits reset with each window and with your billing cycle. Your budget refreshes at the start of every billing cycle, with every model discount already baked in.

How is the 8× multiplier possible?

You pay $10 and code with up to $80 of per-model credit allowances. It works through phenomenal harness and inference engineering: direct capacity deals with model teams, and running our own infrastructure at leading ~95–98% cache hit rates. Most of a coding agent's volume is cache reads, so serving the cache well makes every request dramatically cheaper.

Can I buy extra credits?

Yes, any time. Buy pay-as-you-go credits at model cost — they work on every model (including premium), roll over, and never expire. Buy them from Studio → Billing, 5 to 500 credits at a time, and pay in $ with a card, Alipay, or crypto, or in ₹ with UPI where offered.

Can I use the GOAT plan via API?

Yes. Every plan except Go has API access. You use the same Provider API (OpenAI Chat Completions and Anthropic Messages endpoints, one key for the CLI and the API), so you can integrate GOAT with any other agent. We still recommend the CLI — harness engineering makes the same credits go further.

Is the GOAT plan available worldwide?

Yes. Open-source models run on infrastructure in the US, EU, and Singapore for reliable access worldwide.

Can I enforce zero data retention?

Yes. Most models are ZDR by default — agreements are renewed monthly and can take time for brand-new models. You can also enforce ZDR on every request (which can change model prices based on the provider). Run the CLI with CMD_ZDR=1 — for example, CMD_ZDR=1 cmd — to enforce zero data retention and no prompt training on every request.

Is my code used for training?

No. Never. Your code, your skills, and your memory stay on your machine. Command Code never trains on your work.

Can I change my mind?

Always. Upgrade, downgrade, or cancel from Studio → Billing. No hoops, no penalties. You keep access until the end of your billing cycle, and any unused credits roll over forever.

Why Command Code instead of another agent?

Command Code is the best coding agent for open models. It lives in your terminal and continuously learns your coding taste. Powered by taste-1, it ships, fixes, tests, and refactors with the patterns you keep and forgets the ones you delete — proven at 30T scale, 130T+ tokens served, by 100K+ developers and 40K+ paid customers.
